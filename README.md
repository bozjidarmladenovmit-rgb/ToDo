# DayPilot

> Работно име. Пред објава треба да се избере ново, бидејќи „DayPilot“ веќе го користат други производи.

Мобилна апликација (Android и iPhone) која ве потсетува на сè во секојдневието: терапии, доктор, спорт, хоби, обврски на децата, работа и купување.

## Фаза 1 (готово)

- **8 секции:** терапија/лекови, доктор и здравје, спорт и вежби, хоби, деца, работа и обврски, купување, општо.
- **Потсетници** со датум и време и повторување: еднаш, секој ден, неделно (избрани денови), на секои X часа (на пр. антибиотик на 8 часа), месечно. Можат да имаат краен датум.
- **„Кога да тргнам“:** ако внесете минути за подготовка и за пат, добивате три известувања.
  Пример: тренинг во 10:00, подготовка 10 мин, пат 15 мин → **09:35** „подготви се“, **09:45** „тргни“, **10:00** „почнува“.
- **За кого** е потсетникот (на пр. име на детето) и **каде** се одржува.
- **Листа за купување:** штиклирање и бришење на купените производи.
- **7 јазици:** македонски, англиски, француски, шпански, германски, грчки, италијански. Јазикот се избира сам според телефонот, а може да се смени во ⚙️ Поставки.
- Податоците се чуваат на самиот телефон.

## Фаза 2 (готово)

- **Локации:** адресата се пронаоѓа на мапа, или се користи моменталната локација.
- **Дома:** во ⚙️ Поставки се внесува домашната адреса и вообичаениот начин на патување (автомобил, пешки, велосипед, автобус).
- **Автоматско време на пат:** се пресметува од дома, а во последните 3 часа пред настанот од местото каде што сте. Колку е поблиску настанот, толку почесто се освежува.
  - Со **Google Maps клуч** времето се пресметува со сообраќај во живо.
  - Без клуч апликацијата прави **проценка** според растојанието.
- **Временска прогноза** (Open-Meteo, бесплатно): ако веројатноста за дожд е 50% или повеќе, известувањето ве советува да земете чадор и додава 5 мин за патот.
- **Копчиња на известувањата:** „Готово“ (не потсетува повеќе за тој настан) и „Одложи 10 мин“.
- **Освежување во позадина** на секои ~30 мин, и кога апликацијата е затворена. Ова работи само во вистинска верзија на апликацијата, не во Expo Go.

## Google Maps клуч (опционално)

1. Отворете [Google Cloud Console](https://console.cloud.google.com/) и направете проект.
2. Вклучете го **Routes API** и направете API клуч (APIs & Services → Credentials).
3. Ограничете го клучот само на Routes API и на вашите апликации (Android package `com.daypilot.app`, iOS bundle `com.daypilot.app`).
4. Во папката на проектот направете датотека `.env.local` со содржина:

```
EXPO_PUBLIC_GOOGLE_MAPS_API_KEY=вашиот-клуч
```

Датотеката `.env.local` не се праќа на GitHub. Пред објава на продавниците клучот ќе го преместиме на сервер.

## Пробување на телефон

Потребно е [Node.js](https://nodejs.org) (верзија 20 или понова) на компјутерот и апликацијата **Expo Go** на телефонот (од Google Play или App Store).

```bash
git clone https://github.com/bozjidarmladenovmit-rgb/todo.git
cd todo
npm install
npx expo start
```

Скенирајте го QR-кодот со Expo Go (Android) или со камерата (iPhone). Телефонот и компјутерот треба да се на иста Wi‑Fi мрежа. Ако не се, стартувајте со `npx expo start --tunnel`.

## За програмери

- Expo SDK 58, React Native, TypeScript, Expo Router (`src/app/`).
- Логиката за распоред е во `src/lib/schedule.ts`, известувањата во `src/lib/notifications.ts`, времето на пат во `src/lib/travel.ts`, прогнозата во `src/lib/weather.ts`, освежувањето во `src/lib/engine.ts` и `src/lib/background.ts`, преводите во `src/i18n/translations.ts`.
- Известувањата се закажуваат за следните 14 дена (најмногу 60, поради ограничувањето на iOS) и се обновуваат при секое отворање на апликацијата.

```bash
npm test          # тестови за распоредот
npm run typecheck # проверка на типови
```
